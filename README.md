
# CineVerse - Base de Datos

Este repositorio contiene los scripts SQL utilizados para crear y configurar la base de datos del proyecto CineVerse.

## Contenido

- `01-crear-tablas.sql`: Creación de las tablas del sistema.
- `02-datos-prueba.sql`: Datos iniciales para realizar pruebas.

## Tablas

- **Películas:** Almacena la información de las películas disponibles.
- **Funciones:** Registra las funciones, fechas, horarios, salas, precios y cupos disponibles.
- **Compras:** Almacena las compras de boletos realizadas por los clientes.
- **CineVerse Cards:** Almacena las tarjetas de los usuarios, sus titulares y el saldo disponible.

## Tecnologías utilizadas

- PostgreSQL
- SQL

## Proyecto

CineVerse es un sistema de gestión de cine que permite administrar películas, funciones, compras de boletos y tarjetas de saldo CineVerse Card.
